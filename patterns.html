A system for telling many kinds of story in one voice

Every entry on this site is assembled from three layers. An entry type tunes the page geometry and brings its own masthead fields. A handful of blocks arrange evidence and text. A plate holds one artifact: a photograph, a screenshot, a receipt, a map, a sketch. Nothing below knows what it will eventually hold, which is the point: the layouts are finished, and the assets arrive later.

Adding a real asset is one line of markup. Never a redesign.

Every empty slot below draws a keyline cross and names the kind of artifact it is waiting for. Put an image inside the slot and the placeholder removes itself. No class to change, no layout to rebuild, no dimensions to work out. The slot already knows the shape that kind of artifact should be.

1 · Entry types

Six editorial formats, one visual language. A type sets the reading measure and the margin width, and therefore how much room pictures get, then declares which masthead fields apply. A reader should never have to work out which kind of entry they opened; it should simply feel like another page from the same notebook.

2 · Blocks

Ten arrangements of evidence and text. Every entry type draws on the same ten; the type decides how much room they get. A block never restyles the plates inside it, so any artifact can go in any block.

Observation

.blk-observationText tier

The smallest complete unit: one artifact, what it is, and what it told me. Use when the evidence speaks for itself.

Evidence + Reflection

.blk-evidenceWide tier

One large artifact carrying the block, a hand note set against it, and about a hundred words. The picture leads and the text explains it, not the other way round.

the detail I keep coming back to

About a hundred words of reflection. What was expected, what actually happened, and the part that changed how the next one gets approached. Long enough to hold a thought, short enough that the photograph stays the reason the block exists.

Before / After

.blk-beforeafterWide tier

Two states of the same thing, an arrow, one sentence. Use for a revision, a rebuild, or a site before and after a season. The arrow is drawn rather than typed, so it reads as the same pen as every other mark on the site.

One sentence saying what changed, and what it cost to change it.

Screenshot Insight

.blk-screenshotWide tier

A screenshot with one region called out and explained. Position the keyline with --x, --y, --w and --h as percentages of the slot. The callout is an engineering leader-and-keyline, not a yellow sticky — the site already has a way to point at something, and it is this one.

A

What is happening in the marked region, and why it matters. Add one note per marked region; the letters are the only thing connecting them.

Gallery Strip

.blk-stripFull tier

Many artifacts, scanned sideways, each captioned. Use when the sequence matters more than any single frame. Scrolling is snapped and keyboard-reachable, and it never moves on its own.

Notebook Spread

.blk-spreadWide tier

Left page evidence, right page reflection, one hairline where the fold would be. The only block that borrows the book's geometry, and it collapses to a single column rather than pretending to be a spread on a phone.

Reflection

The right page is where the evidence gets argued with. It can run long or stop after two lines; the fold holds either way.

Process Timeline

.blk-processWide tier

How the thing actually moved: sketch, prototype, pilot, outcome. Set --steps to the number of stages. The sequence is the information, so the steps are numbered.

Sketch

What it looked like before anything was built.

Prototype

The first version that could be handled.

Pilot

In the field, under real conditions.

Outcome

What was still standing afterwards.

Quote

.blk-quoteWide tier

Something someone said, at scale, with the evidence that it was said. Use for the sentence that reframed the problem — not for decoration.

wrote this down before I understood it

Artifact Grid

.blk-artifactsWide tier

Everything that isn't a photograph, mixed at its own proportions. Items span different numbers of columns via --span, so the grid stays irregular the way a real collection of paper is, without a single piece of tape.

Photo Essay block

.blk-essayFull tier

Imagery carries it; text appears only where an image cannot say the thing. Items take --span and optionally --start, so nothing tiles. The composition is asymmetric on purpose.

A short aside, where a picture cannot say the thing.

3 · Evidence

Eleven kinds of artifact, each with a default proportion, because the template should already be the right shape before the asset exists. Line art and paper are shown whole; photographs may be cropped to fill. Set data-artifact and the slot handles the rest.

Artifact types

data-artifact11 kinds

Width tiers

.u-wide.u-full

Three tiers on one grid. Text sits in the reading column by default; add .u-wide or .u-full to break a block out without leaving the flow. This is what lets an entry run 70% visual with no layout rebuilt for it.
