0 · The thesis line

Line one stays printed in Bodoni. Line two is written with a pen, and the plum stroke is drawn underneath it. Each face is optically scaled so they all sit at the same visual size as the serif above — a fine script set at the same pixel size as a serif looks half as big, and would lose the comparison for the wrong reason.

1 · Display candidates

Your actual headline, set at actual size, in each face. Judge the italic too: the second line of the homepage thesis is italic, so it has to hold up.

Bodoni ModaCurrent · Google

The hard part was never the idea.
It’s getting it adopted.

A didone: mathematically constructed, high contrast, unmistakably editorial. The risk is that it is the safe answer — one step sideways from Playfair Display, and it reads fashion-editorial more than field-journal.

ZodiakFontshare · free

The hard part was never the idea.
It’s getting it adopted.

A contemporary serif with blunt, almost architectural terminals and an unusual axis. Most distinctive of the four. Reads deliberate and slightly severe — closer to an engineering document than a magazine.

GambettaFontshare · free

The hard part was never the idea.
It’s getting it adopted.

Calligraphic bones, moderate contrast, a warm and slightly handwritten quality in the italic. The most human of the four — suits a notebook premise without resorting to a script face.

BoskaFontshare · free

The hard part was never the idea.
It’s getting it adopted.

High contrast display serif with very fine hairlines. Closest in feel to Bodoni, so it keeps the current elegance while being far less common. Needs size to work; poor below about 28px.

ErodeFontshare · free

The hard part was never the idea.
It’s getting it adopted.

Organic, slightly weathered edges, as if printed rather than rendered. The most bookish. Carries texture without any of the fake-distress the brief rules out, because the texture is drawn into the outlines.

2 · Body in monospace

The same paragraph in each candidate, at real body size and real measure. Note the words in bold: this is where a single-weight face gives itself away.

Libre FranklinCurrent · 400–700 + italics

I trained as an engineer. Engineering teaches you that a problem is solved when the design works. A few years of fieldwork taught me that a working design is about halfway. Financing that doesn’t match how people actually earn is a constraint.

Fragment Mono400 only · no bold

I trained as an engineer. Engineering teaches you that a problem is solved when the design works. A few years of fieldwork taught me that a working design is about halfway. Financing that doesn’t match how people actually earn is a constraint.

The bold above is fake. Fragment Mono ships one weight, so the browser smears the outline to simulate it. It also does double duty: if body and metadata are the same face, the title blocks and figure labels lose the separate voice that makes the site read as a documented record.

Azeret Mono300–700 + italics

I trained as an engineer. Engineering teaches you that a problem is solved when the design works. A few years of fieldwork taught me that a working design is about halfway. Financing that doesn’t match how people actually earn is a constraint.

A real monospace with real weights, so bold is genuine. If you want a mono body, this is the way to do it — and Fragment Mono would then move aside or go entirely.

What changes if body goes mono

  • Characters per line drop by roughly a third at the same column width, so entries get noticeably longer.
  • Long prose reads more slowly. Fine for captions, labels and short entries; costly for a 2,000-word essay.
  • Body and metadata stop being distinguishable unless the metadata moves to a different face or a much smaller size.
  • It is a strong, deliberate identity: technical, documentary, unmistakably not a template. That is exactly what you asked for.
